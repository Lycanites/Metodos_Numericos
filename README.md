# Metodos_Numericos

## ¿Que hace?

Es un sistema que permite al usuario utilizar diversas metodos de analisis numerico para resolver ecuaciones con el porcentaje de error deseado.

## ¿Que se necesita para que funcione?

Se deben de instalar las carpetas del archivo 'requirements.txt'. Es recomendable iniciar un entorno virtual para no comprometer las librerias que se tienen instaladas.
